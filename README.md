# Full Stack Developer Portfolio

A professional, responsive portfolio website designed for Fiverr, Upwork, direct clients and freelance proposals.

## Files
- `index.html` — portfolio structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation, year, FAQ/contact behavior

## Before publishing
Replace these placeholders in `index.html`:
- `Your Name`
- `YourName`
- `your.email@example.com`
- LinkedIn URL
- GitHub URL
- Project live/demo URLs
- Project screenshots (optional)

## Recommended Fiverr / Upwork setup
Use the portfolio URL in your profile/portfolio section. Add 3–6 real projects with screenshots, measurable outcomes, and your exact role.

## Contact form
The current form uses `mailto:` so it can work without a backend. For a production portfolio, connect it to Formspree, EmailJS, a custom API, or your own backend.
